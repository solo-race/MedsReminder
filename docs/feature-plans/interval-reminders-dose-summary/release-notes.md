## 本分支实现的功能

- 药物计划可选择固定时刻或按间隔；间隔按首次日期时间的固定起点递推，提前/迟服不会重置序列。
- 服药前5分钟预提醒、到点更新同一通知；首页、详情及通知显示倒计时，过点后显示到期/逾期状态。
- 设置增加全局响铃开关，默认开启；关闭后使用静音通知，恢复/重贴不重复响铃。实际声音仍受系统通知权限、通知设置和勿扰设置影响。
- 未处理服药可在重新打开应用后恢复，每次服药拥有独立通知；成功 Taken/Skipped 才清理对应提醒。显式变更计划、禁用或删除会终止原提醒；仅改药名、备注、照片或剂量保留提醒。
- 记录页顶部常驻“剂量汇总”入口，默认近7天，可选今天/近30天；按确认时间、药物和单位分别统计，同名的不同药物也不合并。Skipped不贡献服用量，不同单位和不同药物的量不相加。

## 数据口径

旧记录没有当次剂量快照时明确显示未记录，不用当前药物剂量回填或推断。已有已服次数仍可统计，未知剂量次数单独提示且不计入量的合计。新记录保存当次剂量及文字快照，后续编辑不改旧快照；小数量使用精确十进制求和。

仅统计近30天内保留的记录，删除药物会删除其记录及汇总。今天从设备时区零点到当前时刻；近7天/30天分别回溯7×24/30×24小时。没有全历史总量、跨药物总剂量或剂量单位换算。
