# 周期间隔提醒与剂量汇总 — beta.6 发布说明

版本为 `1.0.0-beta.6` / code 6。P1–P4 已收到主控转达的独立审阅 PASS；后续系统语言和用量编辑的验证范围见下文。远端发布状态以 GitHub Releases 为准。

## 本分支实现的功能

- 药物计划可选择固定时刻或按间隔；间隔按首次日期时间的固定起点递推，提前/迟服不会重置序列。
- 服药前5分钟预提醒、到点更新同一通知；首页、详情及通知显示倒计时，过点后显示到期/逾期状态。
- 设置增加全局响铃开关，默认开启；关闭后使用静音通知，恢复/重贴不重复响铃。实际声音仍受系统通知权限、通知设置和勿扰设置影响。
- 未处理服药可在重新打开应用后恢复，每次服药拥有独立通知；成功 Taken/Skipped 才清理对应提醒。显式变更计划、禁用或删除会终止原提醒；仅改药名、备注、照片或剂量保留提醒。
- 记录页顶部常驻“剂量汇总”入口，默认近7天，可选今天/近30天；按确认时间、药物和单位分别统计，同名的不同药物也不合并。Skipped不贡献服用量，不同单位和不同药物的量不相加。
- 编辑页合并为一个用量区，填写正数数值和单位后自动生成显示文字，避免文字用量与统计用量不一致。旧的纯文字用量在两项留空时保留，不解析旧文字或补写历史快照。

默认语言现在跟随系统首选语言：中文使用简体中文，未支持的语言回退英语。已有手动选择英语/简体中文保持不变；设置页可重新选择“跟随系统”。系统语言变化后，界面及持久待服提醒更新，提醒静默重贴不新增服药决策。新发旅行提示及通知频道名称也使用当前语言。

## 数据口径

旧记录没有当次剂量快照时明确显示未记录，不用当前药物剂量回填或推断。已有已服次数仍可统计，未知剂量次数单独提示且不计入量的合计。新记录保存当次剂量及文字快照，后续编辑不改旧快照；小数量使用精确十进制求和。

仅统计近30天内保留的记录，删除药物会删除其记录及汇总。今天从设备时区零点到当前时刻；近7天/30天分别回溯7×24/30×24小时。没有全历史总量、跨药物总剂量或剂量单位换算。

## 验证与交付边界

用量编辑修改后完整194项单元测试（含11项新增用量输入测试）、lintDebug及assembleDebug通过。2026-11-05 在 Android 16 实机以匹配签名覆盖安装，使用独立合成数据验证自然 PRE/DUE、逾期、提醒入口、剂量快照及分组汇总、统计窗口、系统语言切换和用量编辑；结束后核对原有2个药品、116条记录、照片和设置完整保留，原有8个闹钟已重新安排。详细证据及发行构建结果见 [`../../memory.md`](../../memory.md)。[本地最小验证步骤](local-validation.md)提供复现流程。

静音配置已验证，实际听感、锁屏、重启和厂商后台长期运行仍未验证。首次系统语言切换及一次保存后的编辑导航曾出现未响应，控制条件复测未复现，原因尚未确定；不作为已修复缺陷或完整发布验收。普通应用无法绕过强制停止、撤回通知权限或厂商自启动限制；旧版本未落库通知也不承诺跨重启无损恢复。

发行包路径为 `app/build/outputs/apk/release/app-release.apk`，使用现有发行签名配置；debug实机验证不代表发行包的实机验收。升级必须保留原签名，不得以卸载或清数据绕过签名不一致。
